# 🌾 SmartCrop AI – Intelligent Crop Recommendation System

SmartCrop AI is a full-stack AI-powered web application designed to help farmers and agricultural planners make **data-driven crop decisions** using weather, soil, and regional data.

The system provides **crop recommendations, fertilizer advice, weather forecasts, and yield insights** through an interactive dashboard.

---

## 🚀 Features

- 🌱 AI-based crop recommendation using ML models  
- 🌦️ Real-time weather forecasting  
- 🧪 Fertilizer & nutrient (NPK) advisory  
- 📊 Interactive dashboards and charts  
- 🌍 District-wise crop and climate insights  
- 🔐 User authentication (login & signup)
